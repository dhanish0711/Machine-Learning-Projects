## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/dhanish0711/Machine-Learning-Projects.git
cd Machine-Learning-Projects
```

### Run Any Project

Each project is self-contained. Navigate into a project folder, install its dependencies, and follow its README:

```bash
cd "1. Waiter Tips Prediction with Machine Learning"
pip install -r requirements.txt
python app.py
```

## ➕ Adding a New Project

Follow this convention when adding a new project to keep the repo clean and consistent:

1. **Create a numbered folder**: `N. Project Name/`
2. **Include these files** (at minimum):
   - `README.md` — Project overview, setup instructions, how it works
   - `requirements.txt` — Python dependencies
   - `.ipynb` or `.py` — Main code (notebook or scripts)
   - Dataset file(s) (`.csv`, `.json`, etc.)
3. **Update the projects table** in this root `README.md`
4. **Update the badge count** at the top (`Projects: X / 20`)

### Project README Template

Each project README should include:
- Title with emoji
- Brief description
- Features
- Project structure
- Getting started / installation
- How it works (dataset + model info)
- Tech stack
- License
